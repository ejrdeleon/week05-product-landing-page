🚀 **Week 5 – Client-Server Technologies (ITST 302)**

This week, I built a full responsive product landing page for **Sideout Café** in Lumban, Laguna 🇵🇭 — a real local café with a loyalty program — using **Laravel**, **Blade Components**, and **Tailwind CSS**.

The project focused on building reusable UI components from scratch:

— `<x-navbar />` with a working mobile hamburger menu (vanilla JS, no libraries)
— `<x-hero />` with a loyalty dashboard card mockup
— `<x-feature-card />`, `<x-pricing-card />`, `<x-testimonial-card />`
— `<x-button />` supporting 4 variants (primary, secondary, ghost, outline)
— A clean `<x-footer />` using verified business information

One thing I focused on this week was content integrity — clearly labeling sample pricing and testimonials as academic prototype content instead of presenting them as real business information.

The hardest part was the responsive layout. Getting the hero section to look good at 375px mobile AND 1440px desktop took more iterations than I expected, but that's exactly where mobile-first design clicked for me.

Reflection:

Building with Blade Components made me realize how much cleaner and more maintainable code becomes when you follow the DRY principle in UI development. Writing `<x-feature-card />` 8 times vs copy-pasting the same card HTML 8 times is a massive difference when you need to update the design.
